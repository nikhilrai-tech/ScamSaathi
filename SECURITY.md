# Security policy

ScamSaathi handles sensitive information (suspicious messages, contacts, reports), so please report vulnerabilities privately.

**Do not open a public issue for a vulnerability.** Use GitHub's private reporting:
<https://github.com/nikhilrai-tech/ScamSaathi/security/advisories/new>

Include what you found, how to reproduce it, and the impact. You will get a first answer within 7 days.

**Please never send real people's data** (messages, phone numbers, UPI IDs, Aadhaar/PAN) in a report or issue. Use made-up examples.

In scope: the rule-pack signing and verification, the API (authentication, isolation between organisations, injection),
the app (data leaving the device, permission misuse), and anything that could make the tool unsafe for a user.
Out of scope: scams themselves (report those to 1930 or cybercrime.gov.in), and denial of service by volume.

Until the first release only the `main` branch is supported.
